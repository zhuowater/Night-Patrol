## 1. Product Principle for v0.2.6

Do **not** begin content expansion yet.

v0.2.6 should answer one question:

> Can a first-time closed-playtest player understand what is happening, make meaningful route/card choices, and report useful feedback without the developer sitting beside them?

Therefore the priority order is:

1. Closed-playtest package and feedback form.
2. Attack-chain preview as one source of truth.
3. Map decision clarity.
4. Card predicted-effect clarity.
5. Boss countdown/phase clarity.
6. Release `v0.2.6-demo` only after browser smoke and full checks.

## 2. Non-goals

Do not do these in v0.2.6 unless a playtest blocker forces it:

- Add many new cards.
- Add many new enemies.
- Add large new videos.
- Redesign the whole combat UI.
- Add multi-enemy targeting.
- Start public marketing/Steam page work.

## 5. After v0.2.6

Only after feedback comes in, choose one track:

### Track A: If players are confused

Keep polishing onboarding, terminology, map/card clarity, first combat guidance.

### Track B: If players understand but want more variety

Start v0.2.7 content slice:

- 2-3 new events,
- 1 new enemy with a distinct pressure pattern,
- 2-4 cards/tools that reinforce existing archetypes.

### Track C: If launch/package issues dominate

Do a distribution-only patch:

- signing/notarization notes,
- smaller downloads,
- clearer platform launch troubleshooting,
- GitHub Release asset naming cleanup.
