# v0.2.2 Playtest Candidate 收口计划

## 目标

把当前《夜巡 SOC：边界告警》从“可演示”收口到“可以发给第一批玩家试玩”的 `v0.2.2-demo` 候选版本。

这次不继续堆大功能，重点是让现有内容可信、可验证、可分发：文档同步、规则回归、浏览器试玩、桌面打包、Release 说明和已知问题清单。

## 当前基线

- 代码基线：`77ed657 [verified] Add attack-chain counterplay`
- 产品状态：第一关竖切 demo 已可从标题页跑到 Boss/胜利。
- 主题状态：已从志怪原型重构为网络安全 SOC 主题。
- 机制状态：攻击链压力与反制窗口已进入引擎，不只是 UI 文案。
- 分发状态：Electron、本地打包脚本和 GitHub Actions Release 流程已接入。

## 本轮必须完成

### 1. 文档事实同步

需要把仍停留在旧志怪版本的文档同步到 SOC 版本事实：

- `README.md`
- `docs/IMPLEMENTATION_DETAILS.md`
- `docs/PACKAGING_DISTRIBUTION.md`
- `docs/FIRST_ACT_DEMO_ROADMAP.md`
- 新增 `docs/RELEASE_NOTES_v0.2.2.md`

验收标准：

- 文档主标题与一句话介绍均使用《夜巡 SOC：边界告警》。
- 发布 tag 使用 `v0.2.2-demo`，不再复用 `v0.2.1-demo`。
- 明确列出攻击链机制、反制窗口、结算视频、桌面客户端、已知问题。

### 2. 规则层 scenario 回归

新增 `npm run check:engine-scenarios`，覆盖最小但高价值的规则场景：

- lethal IOC 在敌人意图前击杀敌人。
- C2 偶数回合有 IOC 时拦截噪声。
- C2 偶数回合无 IOC 时注入噪声。
- 凭据链在持续降权窗口清洗噪声，避免抽牌污染。
- 勒索链在算力充足时取消倒计时扣血。
- 勒索链在算力不足时正常扣血。

验收标准：

```bash
npm run check:engine-scenarios
npm run check:attack-chain
npm run check:theme
npm run build
```

全部 exit 0。

### 3. 浏览器试玩 QA

至少跑一轮关键页面冒烟：

- 标题页与难度选择。
- 地图节点选择。
- 普通战斗。
- 高危/Boss 或至少战斗结算路径。
- 奖励页。
- 事件页。
- 情报市场。
- 维护窗口。
- 胜利/失败路径至少验证一个。

验收标准：

- 无白屏。
- 无明显 JS runtime error。
- 关键页面截图留档。

### 4. 桌面打包验证

本地至少执行：

```bash
npm run desktop:pack
```

可选执行：

```bash
npm run desktop:dist
```

验收标准：

- `release/` 下生成本机客户端目录。
- 已知未签名 warning 写入 Release Notes。

## 暂缓，不进入本轮

- 大规模新增卡牌、敌人、事件。
- Boss 多阶段重构。
- 完整资源瘦身。
- 正式代码签名、公证、商业分发。
- Tauri 迁移。
