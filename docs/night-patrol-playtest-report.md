## 1. 一句话结论

这个 demo 已经不是“皮肤套壳”的卡牌游戏：安全响应主题、攻击链反制、IOC/噪声/降权/算力几条机制已经能互相咬合，标准难度完整一局可通关，且中后期能形成构筑感。  

但资深玩家视角看，当前最大问题不是“好不好玩”，而是：**核心循环已经有了，信息表达、操作反馈和数值闭环还没完全跟上。** 具体表现为：地图选择信息不足、卡牌实际无需目标但 UI 强调拖拽、部分抽牌循环存在近似无限/拖长战斗的问题，Boss 战有点过长但压力不够尖锐。

## 2. 完整跑局摘要

### 2.1 路线

本局路线：

1. 边界告警：普通战斗
2. 异常事件：短暂维护窗口，选择升级剧本
3. 高危入侵：精英战
4. 维护窗口：升级
5. 高危入侵：精英战
6. 情报市场：购买工具
7. 高危入侵：精英战
8. 核心域控：Boss

路线评价：

- 我主动选择了偏高风险路线：3 个精英 + 1 个商店 + 1 个维护窗口。
- 这个选择在 Slay the Spire 式玩家逻辑里合理：前期血量充足，尽早打精英拿工具，快速滚雪球。
- 地图实际可支持这种策略，但 UI 上“为什么这条线更好”不够明显。节点名称重复度高，收益/风险缺少量化，分支差异弱。

### 2.2 构筑成型过程

核心构筑最后变成：

- **标记 IOC+**：主引擎，负责叠 IOC，升级后效率明显提升。
- **自动化响应+**：长期防御 + 算力，属于强力 Power。
- **持续监控**：每回合多抽 1 张，增强循环。
- **溯源打击**：IOC payoff，把标记转化为爆发伤害。
- **降噪过滤**：防护 + 降权，后期 Boss 战压伤害非常关键。
- **查询缓存 / 长时日志 / 零信任策略 / 封禁热键**：工具组合提升启动、抽牌、首攻和生存。

这个构筑有明确方向：**IOC 标记 → 抽牌维持 → 溯源收割 → 自动化响应兜底防御。** 这是本 demo 最值得保留的部分。

### 2.3 战斗结果

| 楼层 | 节点 | 敌人 | 回合数 | HP 变化 | 评价 |
|---:|---|---|---:|---|---|
| 1 | 普通战斗 | 钓鱼载荷 | 2 | 84 → 84 | 初战节奏快，但敌人连续 debuff，无伤通过 |
| 3 | 精英 | 凭据窃取器 | 4 | 84 → 73 | 第一波真实压力，凭据抓取多段伤害有效 |
| 5 | 精英 | C2 操作员 | 4 | 73 → 73 | IOC + 自动化响应成型，压力降低 |
| 7 | 精英 | 凭据窃取器 | 9 | 73 → 73 | 战斗偏拖，抽牌循环开始过强 |
| 8 | Boss | 勒索核心 | 14 | 73 → 56 | 时长足够，但中后段变成例行堆防 + 慢磨 |

## 3. 资深玩家主观体验

### 3.1 第一印象

优点：

- 标题、背景、HUD、卡牌命名都在统一表达“夜班 SOC + 攻击链响应”。
- “IOC / 噪声告警 / 降权 / 算力 / 自动化响应”不是简单换皮，而是能映射到安全语义。
- 顶部 HUD 有资源、牌组、遗物、地图进度，Roguelike 信息骨架完整。

问题：

- 第一眼“像游戏”，但第一眼“不知道下一步该点哪”。
- 地图页视觉氛围好，但路线线条、节点层级、当前可选节点、确认动作的表达偏弱。
- 战斗页信息很密：左侧攻击链解释、右侧敌人意图、底部手牌、顶部资源同时出现，新玩家会阅读过载。

### 3.2 卡牌手感

当前卡牌池已经有三类有效组件：

1. 启动/循环：日志检索、关联分析、快速 triage、持续监控、查询缓存。
2. 防御/控制：加固规则、降噪过滤、临时隔离、自动化响应。
3. 标记/爆发：标记 IOC、批量标记、资产测绘、溯源打击、沙箱引爆、YARA 命中。

资深玩家能明显读出“流派”：

- IOC 标记流
- 抽牌循环流
- 自动化防御流
- 算力爆发流

但目前有一个手感问题：**0 费抽牌/防御链过于丝滑，且缺少回合内限制提示。** 跑局中后期出现多次单回合连续 `日志检索 / 关联分析 / 快速 triage` 的长链，实际体验会让战斗从“决策”变成“把能打的都打出去”。

### 3.3 敌人设计

敌人语义很好：

- 钓鱼载荷：凭据喷洒，多段攻击/降权。
- C2 操作员：强度增长 + 噪声注入。
- 凭据窃取器：多段压力 + blockAttack。
- 勒索核心：高额攻击、多段破坏、强度唤醒、核心驻留。

问题是敌人的“攻击链机制”还没有足够变成差异化解题：

- 大多数时候最优策略仍然是：有抽牌先抽，有 Power 先下，能防就防，剩余打伤害。
- “优先标记 IOC / 降权 / 算力回滚”这些反制文案很有味道，但战斗中不够显著地改变我的操作顺序。
- Boss 有 14 回合长度，但中后段降权层数堆高后，压力下降，变成慢磨。

## 4. 关键问题清单（按优先级）

### P0：战斗结束可能延迟到敌方回合，造成“明明打到低血但还没赢”的体验

跑局日志里多次出现敌人被压到极低血量但没有立即结算的情况，例如 Boss 第 14 回合行动后敌人只剩 `2 HP`，最后依赖回合结束后的 IOC 持续伤害进入胜利动画。  

如果这不是设计意图，会造成资深玩家困惑：我明明打出了一套爆发，为什么没有立刻击杀？建议检查：

- `playCard()` 里 `if (combat.enemy.hp <= 0) winCombat(state)` 已存在；
- 但是否存在某些伤害来源、动画状态或脚本策略导致没有直观表现；
- UI 是否没有明确展示“IOC 持续伤害将在敌方回合触发”。

建议：当敌人低血且有 IOC 时，UI 显示“回合结束将处置”预测；或者将持续 IOC 触发时机改得更易理解。

### P0：卡牌交互提示与实际逻辑不一致

UI 文案出现“拖到目标身上施放”，攻击牌也写“拖拽到目标区域执行”。但从引擎逻辑看，`playCard(state, uid)` 不需要目标参数，所有牌都是按 UID 直接结算到当前敌人或自身。  

这会带来两个问题：

- 玩家以为需要精准拖拽，但实际点击/释放即可。
- 未来如果加入多敌人或目标选择，现在的文案会造成迁移成本。

建议短期二选一：

1. 如果短期只有单敌人：改文案为“点击或拖出施放，攻击默认命中当前攻击链”。
2. 如果准备做多目标：尽快把目标选择接入引擎，不要继续积累无目标假象。

### P1：0 费抽牌循环过强，导致后期单回合操作冗长

跑局中第 7 层精英、第 8 层 Boss 出现很长的 0 费循环链。核心来源：

- 日志检索：0 费抽 2。
- 关联分析：0 费抽 1，有 IOC 额外抽。
- 快速 triage：0 费防护 + 抽 1。
- 持续监控：每回合 +1 抽。
- 查询缓存：每 3 张牌额外抽 1。

这些组件组合后，手牌运转过顺；敌人又没有足够惩罚“多打牌”或“过牌”。结果是中后期回合长度变长，但决策密度下降。

建议：

- 日志检索可考虑从 `0 费抽 2` 改成 `1 费抽 3`，或 `0 费抽 1，若目标有 IOC 再抽 1`。
- 快速 triage 保留 0 费，但升级前只防护不抽牌，升级后再抽 1。
- 查询缓存触发改为“每回合首次打出第 3 张牌抽 1”，避免长链滚动。
- 给某些敌人加入“每回合打出第 N 张牌后注入噪声/强度 +1”的反循环机制。

### P1：地图决策信息不足

地图页让我知道“我要选路线”，但不知道“为什么选这个”。尤其前两列多个“边界告警”同名，节点详情也完全相同。

建议补充：

- 节点悬浮/详情展示：预计奖励、风险等级、可能敌人池。
- 路线预览：当前节点通向哪些二跳节点，用高亮线展示。
- 同名节点增加副标题：如“边界告警 / 凭据迹象”“边界告警 / 端口扫描”。
- 可选节点卡片加明确按钮：“前往此节点”。

### P1：Boss 战时长够，但阶段感不足

Boss 打了 14 回合，理论上是完整终局战长度。但体验上不是“阶段推进”，而是重复处理类似意图。

建议：

- Boss HP 70% / 35% 触发阶段文案和机制变化。
- 加一个“勒索倒计时”可视化槽，而不是只在日志里提示。
- 让算力反制勒索成为关键解法，例如每 3 回合没有 2 点算力就爆一次真实伤害。
- Boss 低血阶段减少防护，增加爆发，避免最后 30 HP 慢磨。

### P2：安全术语与修仙素材之间存在风格拉扯

代码与资源里仍有一些旧命名/修仙语义，例如 `zhusha`、`incense`、`citygod`、`tigerlord`、`waterghost`，但 UI 文案已改为 SOC 主题。玩家看到界面问题不大，但后续维护和内容扩展时容易混乱。

建议：

- 内部 ID 后续可以逐步迁移到 cybersec 命名，至少新增内容别继续沿用旧语义。
- 卡牌/工具说明保持安全语义，少出现“法门”等残留词。例如持续监控当前文本是“法门：每回合多抽 1 张牌”，建议改为“持续效果：每回合多抽 1 张牌”。

## 5. 数值与平衡建议

### 5.1 当前标准难度体感

标准难度目前偏“可通关、压力中低”。本局路线很贪，打了 3 个精英，但仍以 `56/84` 通关。说明：

- 前期普通怪压力偏低。
- 精英第一场能造成威胁，但一旦拿到自动化响应/持续监控/查询缓存后，生存稳定性很高。
- Boss 主要靠长度消耗，不靠爆发击杀压力。

### 5.2 建议调参方向

不要简单加敌人血量。当前更需要增加“解题压力”：

- 对凭据类敌人：如果玩家没有降权，噪声污染更明显。
- 对 C2 类敌人：如果玩家没有 IOC，周期性注入噪声或强度增长。
- 对勒索 Boss：如果玩家没有算力，触发真实伤害或临时封锁抽牌。
- 对玩家：降低 0 费抽牌链上限，而不是砍所有牌数值。

### 5.3 卡牌建议

| 卡牌 | 当前感受 | 建议 |
|---|---|---|
| 日志检索 | 0 费抽 2 太强 | 改 1 费抽 3，或 0 费条件抽 2 |
| 快速 triage | 0 费防护+抽牌强 | 未升级不抽牌，升级抽 1 |
| 关联分析 | 有 IOC 后过牌很强 | 保留，但加强“需要 IOC”的表达 |
| 自动化响应 | 非常强，拿到后稳定性大增 | 可保留稀有强度，但 Boss 对 Power 有反制更好 |
| 溯源打击 | 概念好，爆发感略弱 | 增加击杀/大额命中特效与预估伤害 |
| 降噪过滤 | 后期压 Boss 很强 | 好牌，建议让敌人 UI 更明显显示降权收益 |

## 6. UI/UX 反馈

### 6.1 标题页

优点：

- 三个难度清楚，推荐态明确。
- 赛博安全主题表达明确。

建议：

- “接管夜班”按钮点击后的 loading/转场反馈可以更强。我实际测试中偶发感觉点击没反应，可能是加载延迟 + 状态变化不明显。
- 难度卡选中态需要更醒目，避免误点挑战难度。

### 6.2 地图页

优点：

- 日志 + 路线图 + 节点详情结构正确。
- “提前看两步”的设计方向对 Roguelike 是对的。

问题：

- 路线连线交叉且偏暗。
- 当前节点、可选节点、已访问节点层级不够分明。
- 节点说明没有差异化收益/风险。

建议优先改地图，因为它决定玩家是否觉得自己在“做路线策略”。

### 6.3 战斗页

优点：

- 敌人意图、HP、防护、IOC、噪声、算力都已经有位置。
- 左侧攻击链解释有主题厚度。

问题：

- 信息太多但优先级不够。
- 手牌倾斜和遮挡影响快速读牌。
- 卡牌 hover/选中态、目标高亮、伤害预估还不够。

建议：

- 手牌 hover 放大更明显。
- 攻击牌 hover 敌人显示预计伤害；技能牌 hover 自身显示预计防护/抽牌。
- 敌方意图旁直接显示“预计受到伤害：X / 防护后 Y”。
- 左侧攻击链说明可折叠，首次遇到敌人展开，之后默认收起为关键反制标签。

### 6.4 奖励、商店、事件

优点：

- 奖励选牌能形成构筑方向。
- 事件选择有安全场景语义。
- 商店有牌、工具、删牌基础功能。

建议：

- 奖励牌应标注稀有度和构筑标签：循环 / IOC / 防御 / 爆发 / 算力。
- 商店预算不足时按钮状态和原因更明确。
- 事件选择要显示当前 HP/预算变化预览，减少玩家心算。

## 7. 最值得保留的设计

1. **安全响应主题是真的能成立。** IOC、噪声、降权、算力不是空文案，能落到卡牌机制上。
2. **攻击链反制文案很有潜力。** “凭据喷洒污染抽牌”“C2 信标回连”“勒索恢复演练”等，比普通怪物技能更有记忆点。
3. **构筑方向已经可读。** 本局形成了自动化响应 + IOC + 抽牌 + 溯源的稳定流派。
4. **路线结构正确。** 普通、精英、事件、商店、休息、Boss 的骨架已经完整。
5. **标准难度可完整通关。** 至少 demo 的闭环已经打通。

## 8. 下一轮迭代建议

### 必做 1：先修“表达一致性”

- 改卡牌操作提示：点击/拖出都可施放，单敌人默认命中。
- 地图节点增加确认按钮和二跳高亮。
- “法门”等残留修仙词改成安全产品语义。

### 必做 2：削弱无限循环倾向

- 调整 0 费抽牌。
- 查询缓存限制每回合一次。
- 敌人加入反多牌/反过牌机制。

### 必做 3：强化 Boss 阶段

- 做 2~3 个阶段。
- 明确勒索倒计时 UI。
- 让算力成为 Boss 关键资源。

### 必做 4：增强伤害/防护预测

- 卡牌 hover 显示预计结果。
- 敌人意图显示本回合需要多少防护。
- IOC 持续伤害显示下回合预期。

## 9. 结论

以资深卡牌 Roguelike 玩家视角，这个版本已经具备“能玩完一局，并且愿意讨论构筑”的基础。它最强的地方是主题机制：安全响应不是贴皮，而是和卡牌动作产生了对应关系。  

但下一步不要急着堆更多卡、更多敌人。当前最应该做的是：

1. 让玩家更清楚自己为什么选路线；
2. 让玩家更清楚一张牌打出后会发生什么；
3. 限制 0 费抽牌链，让回合更短但决策更硬；
4. 把 Boss 从“长血条”改成“阶段化安全事故”。

如果按这个方向打磨，`夜巡 SOC` 会从一个完成度不错的 demo，变成一个有自己题材壁垒的安全主题卡牌 Roguelike。
