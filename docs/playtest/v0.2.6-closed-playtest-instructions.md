# 《夜巡 SOC：边界告警》v0.2.6 闭门试玩说明

> 目标：让试玩者在没有开发者陪同的情况下，完成一次 20-30 分钟的第一章 demo，并提交可执行反馈。

## 1. 下载地址

请从 GitHub Release 下载最新试玩包：

<https://github.com/zhuowater/Night-Patrol/releases/tag/v0.2.6-demo>

> 当前可试玩基线是 `v0.2.6-demo`。本说明用于本轮闭门试玩分发。

## 2. 选择对应平台文件

Release 页面里通常会看到这些资产：

| 平台 | 推荐下载 | 备注 |
|---|---|---|
| Windows x64 | `.exe` 安装包，或 `win` / `windows` `.zip` | 如果安装包被系统拦截，可先试 zip 版。 |
| macOS Apple Silicon / Intel | `.dmg`，或 `mac` `.zip` | demo 阶段未做 Apple 公证，首次打开可能需要手动确认。 |
| Linux x64 | `.AppImage`，或 `linux` `.zip` | AppImage 可能需要先加执行权限。 |

如果不确定下哪个文件：优先下载与你系统同名、体积最大的桌面包；不要下载 `Source code`，那是源码，不是可直接试玩的客户端。

## 3. 启动方式

### Windows

1. 下载 `.exe` 或 `.zip`。
2. 如果是 zip，先完整解压，不要在压缩包内直接运行。
3. 双击启动游戏。
4. 如果 Windows Defender / SmartScreen 提示未知发布者：选择“更多信息”→“仍要运行”。

### macOS

1. 下载 `.dmg` 或 `.zip`。
2. 打开后将 App 拖入 Applications，或直接运行解压后的 App。
3. 如果提示“无法验证开发者”：
   - 在 Finder 中右键点击 App；
   - 选择“打开”；
   - 在弹窗中再次确认“打开”。
4. 如果仍被拦截，可在“系统设置 → 隐私与安全性”底部允许本应用。

### Linux

1. 下载 `.AppImage`。
2. 加执行权限：

```bash
chmod +x Night-Patrol*.AppImage
```

3. 运行：

```bash
./Night-Patrol*.AppImage
```

如果 AppImage 无法启动，请记录终端报错并反馈。

## 4. 建议试玩流程

请尽量完整跑一局，不需要刻意追求最优解：

1. 从标题页进入游戏。
2. 选择难度：第一次建议选“标准值班”；如果只想看流程，可选“演示模式”。
3. 在地图上选择路线。
4. 至少完成：
   - 第一场普通战；
   - 一次奖励选择；
   - 一次事件 / 市场 / 维护窗口；
   - 一场高危战；
   - Boss 战或尽量推进到 Boss 前。
5. 试玩结束后填写反馈表：`docs/playtest/v0.2.6-feedback-form.md`。

预计时间：

- 快速体验：10-15 分钟；
- 完整跑局：20-30 分钟。

## 5. 重点观察什么

请重点观察这些问题：

1. 你是否知道下一步该点哪里？
2. 地图路线选择是否像“决策”，还是像随机点格子？
3. 卡牌效果是否能在打出前看懂？
4. IOC、算力、防护、噪声、降权这些安全概念是否大致能理解？
5. 攻击链反制提示是否让你知道“为什么这次少掉血 / 没掉血”？
6. Boss 是否有阶段变化和压迫感？
7. 哪些文字像黑话，哪些提示太晚出现？
8. 音效、视频、动效是否干扰操作？
9. 有没有卡死、黑屏、按钮无响应、窗口尺寸异常？
10. 如果只能改一件事，你最希望先改什么？

## 6. 反馈时请附带的信息

如果出现问题，请尽量提供：

- 操作系统：Windows / macOS / Linux，以及大致版本；
- 下载的文件名；
- 问题发生的位置：标题页 / 地图 / 战斗 / 奖励 / 商店 / Boss / 结算；
- 你最后点击或打出的内容；
- 截图或录屏；
- 如果是 Linux，从终端启动时的报错文本。

## 7. 当前已知限制

- demo 还没有正式代码签名 / Apple 公证，因此系统可能提示未知开发者。
- 规则说明仍在打磨，部分安全术语可能需要更多新手提示。
- 第一章内容已经能完整跑通，但平衡、Boss 表达、卡牌预测文本仍在 v0.2.6 继续优化。
- 视觉素材和音频仍属于原型阶段；如未来正式公开发行，需要进一步清理授权和替换资产。
