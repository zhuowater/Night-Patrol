## 3. 启动方式

### Windows

1. 下载 `.exe` 或 `.zip`。
2. 如果是 zip，先完整解压，不要在压缩包内直接运行。
3. 双击启动游戏。
4. 如果 Windows Defender / SmartScreen 提示未知发布者：选择“更多信息”→“仍要运行”。

### macOS

1. 下载 `.dmg` 或 `.zip`。
2. 打开后将 App 拖入 Applications，或直接运行解压后的 App。
3. 如果提示“无法验证开发者”：
   - 在 Finder 中右键点击 App；
   - 选择“打开”；
   - 在弹窗中再次确认“打开”。
4. 如果仍被拦截，可在“系统设置 → 隐私与安全性”底部允许本应用。

### Linux

1. 下载 `.AppImage`。
2. 加执行权限：

```bash
chmod +x Night-Patrol*.AppImage
```

3. 运行：

```bash
./Night-Patrol*.AppImage
```

如果 AppImage 无法启动，请记录终端报错并反馈。

## 4. 建议试玩流程

请尽量完整跑一局，不需要刻意追求最优解：

1. 从标题页进入游戏。
2. 第一次建议选“标准值班”；如果只想看流程，可选“演示模式”。
3. 第一场战斗先观察：
   - 敌方意图；
   - 回合级“建议响应”；
   - 哪些手牌被提示为当前威胁的解法。
4. 在地图上选择路线，只需要优先看当前可选节点；远端“待侦察”节点是未来预览。
5. 至少完成：
   - 第一场普通战；
   - 一次奖励选择；
   - 一次事件 / 市场 / 维护窗口；
   - 一场高危战；
   - Boss 战或尽量推进到 Boss 前。
6. 试玩结束后填写反馈表：`docs/playtest/v0.2.9-feedback-form.md`。

预计时间：

- 快速体验：10-15 分钟；
- 完整跑局：20-30 分钟。

## 5. 本版重点观察什么

v0.2.9 的重点不是新增内容，而是降低第一次跑局的认知负担。请重点观察：

1. 第一场战斗中，你是否知道“这回合先做什么”？
2. 回合级建议是否有帮助？有没有明显误导？
3. 第一次看到 C2 信标时，你是否知道 IOC 可以拦截它？
4. 第一次看到噪声告警时，你是否知道它是坏牌 / 告警债？
5. “响应算力”和“临时算力”是否清楚？
6. 奖励页第一眼是否在看三张候选牌，而不是被日志/工具说明抢走？
7. 地图是否让你聚焦当前可选节点，而不是被全图压住？
8. 专家攻击链详情折叠后，战斗界面是否更容易读？
9. Boss 的倒计时/阶段文案是否告诉你该准备防护、IOC 或临时算力？
10. 有没有卡死、黑屏、按钮无响应、窗口尺寸异常？

## 6. 反馈时请附带的信息

如果出现问题，请尽量提供：

- 操作系统：Windows / macOS / Linux，以及大致版本；
- 下载的文件名；
- 问题发生的位置：标题页 / 地图 / 战斗 / 奖励 / 商店 / Boss / 结算；
- 你最后点击或打出的内容；
- 截图或录屏；
- 如果是 Linux，从终端启动时的报错文本。

## 7. 当前已知限制

- demo 还没有正式代码签名 / Apple 公证，因此系统可能提示未知开发者。
- 第一章内容已经能完整跑通，但平衡和教学仍会继续根据闭门试玩反馈调整。
- 视觉素材和音频仍属于原型阶段；如未来正式公开发行，需要进一步清理授权和替换资产。
- v0.2.9 不新增卡牌、敌人、存档或元进度，主要是首次引导、分发入口、资源治理和短视口关键选择页打磨。
