## 4. 当前分发建议

可以开始小范围闭门分发，但建议分发时直接复制“短消息”而不是只丢 Release 链接：

1. Windows 用户优先给 `.exe`，若 SmartScreen 拦截严重，再让其下载 `.zip`。
2. macOS 目前只明确 Apple Silicon；Intel 用户需要单独标注“本轮未提供 Intel 专用包”。
3. Linux 用户优先给 AppImage，并提醒 `chmod +x`。
4. 每位试玩者都要求回传：系统、下载文件名、是否成功启动、第一战是否知道做什么、是否理解 C2/IOC/噪声、最想优先改一件事。

## 5. v0.2.9 后续决策门槛

收齐至少 5 份有效反馈后，再进入下一轮实现。建议按以下规则排优先级：

- **P0**：任何平台启动失败、第一战不知道如何操作、C2/IOC/噪声多人没理解。
- **P1**：奖励、地图、Boss 阶段、性能中出现多人低分但不阻断试玩的问题。
- **P2**：单人偏好、文案小修、非阻断视觉噪声。

如果反馈样本不足 5 份，不建议立刻扩内容；可以继续做发布工程自动化或等待反馈。
