## 3. 启动方式

### Windows

1. 下载 `.exe` 或 `.zip`。
2. 如果是 zip，先完整解压，不要在压缩包内直接运行。
3. 双击启动游戏。
4. 如果 Windows Defender / SmartScreen 提示未知发布者：选择“更多信息”→“仍要运行”。

### macOS

1. 下载 `.dmg` 或 `.zip`。
2. 打开后将 App 拖入 Applications，或直接运行解压后的 App。
3. 如果提示“无法验证开发者”：
   - 在 Finder 中右键点击 App；
   - 选择“打开”；
   - 在弹窗中再次确认“打开”。
4. 如果仍被拦截，可在“系统设置 → 隐私与安全性”底部允许本应用。

### Linux

1. 下载 `.AppImage`。
2. 加执行权限：

```bash
chmod +x Night-Patrol*.AppImage
```

3. 运行：

```bash
./Night-Patrol*.AppImage
```

如果 AppImage 无法启动，请记录终端报错并反馈。

## 4. 建议试玩流程

请尽量完整跑一局，不需要刻意追求最优解：

1. 从标题页进入游戏。
2. 第一次建议选“标准值班”；如果只想看流程，可选“演示模式”；如果你熟悉卡牌肉鸽，可第二局试“挑战模式”。
3. 第一场战斗先观察：
   - 敌方意图；
   - 回合级“建议响应”；
   - 哪些手牌被提示为当前威胁的解法。
4. 在地图上选择路线，只需要优先看当前可选节点和右侧“进入该节点”卡片；远端节点只是未来预览。
5. 奖励页和市场页请留意顶部“当前构筑诊断”，看看它是否真的影响你的选择。
6. 尽量推进到 Boss，并在 Boss 入场前留意自己血量是否危险。
7. 结算后不要马上关闭：请看“本局 SOC 复盘”，尝试复述本局为什么赢/输、下一局该改什么。
8. 试玩结束后填写反馈表：`docs/playtest/v0.2.10-feedback-form.md`。

预计时间：

- 快速体验：10-15 分钟；
- 完整跑局：20-30 分钟。

## 5. 本版重点观察什么

v0.2.10 的重点不是新增内容，而是让一局结束后更可学习。请重点观察：

1. 第一局结束后，你是否知道为什么赢/输？
2. 复盘页中路线、战斗、事件、奖励、工具和 Boss 入场血线哪部分最有用？
3. 复盘页的死亡/胜利原因推断是否准确，还是在“瞎总结”？
4. 你是否知道下一局该改路线、构筑还是战斗打法？
5. 事件路线让你觉得赚了、亏了，还是只是读故事？
6. 奖励页/商店的“当前构筑诊断”是否帮助你做选择？
7. Boss 入场前你是否知道血线危险？Boss 阶段提示是否告诉你要准备什么？
8. 短视口下关键操作是否优先，专家态势是否该折叠？
9. 有没有卡死、黑屏、按钮无响应、窗口尺寸异常？

## 6. 反馈时请附带的信息

如果出现问题，请尽量提供：

- 操作系统：Windows / macOS / Linux，以及大致版本；
- 下载的文件名；
- 问题发生的位置：标题页 / 地图 / 战斗 / 奖励 / 商店 / Boss / 结算；
- 你最后点击或打出的内容；
- 结算复盘页截图，尤其是你觉得总结错了的时候；
- 如果是 Linux，从终端启动时的报错文本。

## 7. 当前已知限制

- demo 还没有正式代码签名 / Apple 公证，因此系统可能提示未知开发者。
- 第一章内容已经能完整跑通，但平衡和教学仍会继续根据闭门试玩反馈调整。
- v0.2.10 不新增卡牌、敌人、章节、存档或元进度，主要修“复盘可学习、事件补偿、短视口层级、构筑诊断”。
- 视觉素材和音频仍属于原型阶段；如未来正式公开发行，需要进一步清理授权和替换资产。
