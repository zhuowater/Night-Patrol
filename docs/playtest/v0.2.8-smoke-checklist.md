## 3. 第一场战斗

- [ ] 玩家能看到敌方意图、自己 HP、响应算力、临时算力、防护。
- [ ] 第一战 first-run cue 出现，文案短，不遮挡手牌或结束回合按钮。
- [ ] cue 可点击 `知道了` dismiss。
- [ ] 出牌或结束回合后 cue 不再阻塞当前操作。
- [ ] 回合级 `建议响应` 可见，并与当前敌方意图/手牌大体一致。
- [ ] 至少一张手牌出现“解决当前威胁”的推荐 ribbon，或当前场景确实没有匹配推荐。
- [ ] 拖拽出牌和点击出牌都可用。

## 4. 攻击链与微提示

尽量观察 C2、凭据、勒索相关敌人：

- [ ] C2：首次 C2 cue 出现一次，并明确提到 IOC 可以拦截。
- [ ] C2：IOC 条件显示 `IOC ≥ 1`，缺失时显示 `还差 1 IOC`。
- [ ] 噪声：首次噪声 cue 出现一次，并解释为坏牌 / 告警债。
- [ ] 凭据：显示降权和噪声当前值。
- [ ] 勒索：显示临时算力条件和倒计时状态。
- [ ] 卡牌提示不推荐无法打出/响应算力不足/不可用的牌。
