# v0.2.2-demo Release Notes

## 一句话

`v0.2.2-demo` 是《夜巡 SOC：边界告警》的第一批试玩候选版：完整第一关、网络安全主题、攻击链压力、玩家反制窗口、胜利结算视频和桌面客户端分发流程进入同一条闭环。

## 适合谁试玩

- 想快速体验一个 SOC 题材卡牌 roguelike 原型的玩家。
- 愿意反馈“规则是否看得懂、出牌是否有策略感、界面哪里不像游戏”的朋友。
- 可以接受 demo 阶段未签名、包体偏大、素材授权仍需正式化的测试者。

## 主要更新

### 1. 网络安全主题竖切

游戏从旧志怪原型转为“夜班 SOC 响应员”视角：

- 路线变成从边界、办公网、终端、日志湖到核心域控的攻击路径。
- 敌人变成端口扫描器、钓鱼载荷、僵尸进程、横向移动脚本、C2 操作员、凭据窃取器、勒索核心。
- 资源、状态和卡牌语义统一为 IOC、算力、防护、降权、暴露面、噪声告警、情报市场、维护窗口。

### 2. 攻击链压力与反制窗口

攻击链已经进入规则层，不只是换文案：

- **C2 指挥控制**：偶数回合可能注入噪声告警；如果目标身上有 IOC，会消耗 IOC 拦截本轮信标。
- **凭据喷洒/滥用**：噪声过多会污染抽牌；如果敌人处在持续降权窗口，会在抽牌前清洗噪声。
- **勒索加密**：倒计时回合会造成额外生命损失；如果保留足够算力，会消耗算力执行恢复演练并取消扣血。
- UI 增加“风险预告”和“反制窗口”，提示玩家为什么要标记 IOC、保留算力或施加降权。

### 3. 可跑通的第一关 demo

当前内容包括：

- 标题页、难度选择、路线地图。
- 普通战、高危战、Boss 战。
- 事件、情报市场、维护窗口、删牌、升级。
- 卡牌奖励、预算奖励、工具奖励。
- React UI + Phaser 战斗舞台。
- 背景音乐、操作音效、战斗音效。
- 战斗胜利结算视频与静态 fallback。

### 4. 验证与回归

新增/保留以下检查：

```bash
npm run check:engine-scenarios
npm run check:attack-chain
npm run check:theme
npm run build
```

`check:engine-scenarios` 覆盖 lethal IOC、C2 有/无 IOC、凭据清洗、勒索有/无算力等关键规则场景。

## 已知问题

- **未签名**：macOS/Windows 测试包可能提示未知开发者或无法验证开发者。
- **包体偏大**：当前 `dist` 与 generated assets 仍包含较大的视频、poster PNG、BGM 和背景视频。
- **Vite chunk warning**：构建时可能提示 chunk 超过 500KB；当前作为已知非阻塞问题处理。
- **素材授权仍需确认**：部分素材来自用户下载素材包或 AI 生成，正式公开发行/商业化前需要重新核查或替换。
- **平衡仍是 demo 级**：可玩目标优先于严格平衡；欢迎反馈过强、过弱、看不懂的卡牌或敌人。

## 试玩反馈优先级

请优先反馈：

1. 是否知道下一回合风险是什么。
2. 是否理解 IOC、算力、降权分别能反制什么。
3. 是否有“我做了一个正确安全响应决策”的感觉。
4. 哪些界面仍像网页，不像游戏。
5. 哪些地方卡顿、白屏、无法继续或看不到按钮。
