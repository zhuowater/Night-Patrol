## 1. 启动与第一印象

1. 下载、安装、打开游戏是否顺利？  
   评分 1-5：**5**  
   说明：本地 `npm run dev`、`npm run check`、`npm run build` 均通过；浏览器无阻塞启动问题。桌面包安装未在本轮实测。

2. 标题页是否让你知道这是什么游戏、你扮演谁、目标是什么？  
   评分 1-5：**4**  
   最清楚的是：标题、SOC 值班/边界告警主题、难度选择和“接管夜班”CTA 都很明确。  
   最不清楚的是：资深玩家能理解“安全响应 deckbuilder”，但真正第一次接触的人可能还不知道“胜利条件=穿过 8 层攻击链并阻断核心域控”。建议标题页加一句更硬的目标句：**“8 个节点内构筑响应剧本，天亮前阻断勒索核心。”**

3. 标题页、地图、底部按钮有没有被裁切或挤压？  
   评分 1-5：**4**  
   如果有，请说明位置并附截图：标题页完整；地图页当前可选节点清楚，但在 581px 高度下第二张可选路线卡会落到首屏较下方；奖励页三张候选牌的下半部分在截图中被截断，虽然 aria/可点击文本完整，但视觉上需要滚动或更高窗口才能看完效果。

## 2. 第一战与回合建议

4. 第一场战斗中，你是否知道“这回合先做什么”？  
   评分 1-5：**4**  
   卡住或试错的地方：回合建议、敌方意图、手牌威胁提示已经能让我知道先补 IOC / 防护 / 伤害。但第一战页面仍然同时出现“攻击链态势、反制窗口、响应日志、手牌、资源”多层信息；资深玩家能吃下，新手可能会先乱点几张低费牌。

5. 第一战 cue 是否有帮助？  
   - **有帮助**  
   原因：它把阅读顺序从“看一堆卡牌”改成“先看敌方意图→再看建议→再出牌”。这点相比 v0.2.7 的资深玩家反馈是明显进步。

6. 回合级“建议响应”是否有用？有没有误导？  
   评分 1-5：**4**  
   最有用的一条建议：敌方高压或 C2 窗口时提示优先补防护/IOC，能快速建立战斗目标。  
   误导或多余的一条建议：当手牌里有多张“看起来都能解决威胁”的牌时，建议条还不能明确告诉我“本回合最优先的 1-2 张牌”与“可后置牌”。资深玩家希望看到更强的优先级排序。

7. 哪张卡的“解决当前威胁”提示最有用？有没有提示错了的牌？

   **标记 IOC+ / 关联分析+ / 快速 triage** 最有用，因为能把 C2、凭据滥用和攻击链反制连起来。未观察到明显提示错误；但“阻断连接”这种基础攻击牌在多数局面都可打，提示价值不如 IOC 类卡，建议进一步突出“为什么此刻值钱”。

## 3. C2、噪声与资源理解

8. 第一次看到 C2 信标时，你是否理解 IOC 可以拦截它？  
   - **一眼理解**  
   哪个提示帮助了你，或为什么没懂：C2 cue + IOC 牌文案 + 攻击链反制日志共同形成闭环。自动 probe 中 C2 操作员战斗多次出现“IOC 复核让 C2 指挥控制暂停扩散”，反馈很明确。

9. 第一次看到噪声告警时，你是否理解它是坏牌 / 告警债？  
   - **后来理解**  
   说明：事件“申请预算：获得 80 预算，将 1 张噪声告警加入牌组”已经能表达代价；但如果没有真的抽到噪声，玩家对“污染有多痛”的体感还不强。建议噪声首次入牌组时给一个更短的风险句：**“它会占用抽牌机会，不提供有效处置。”**

10. 以下概念你能理解多少？

| 概念 | 理解程度 | 哪个提示帮助了你 / 为什么不懂 |
|---|---|---|
| IOC | 清楚 | 标记 IOC、C2 cue、反制日志都指向“识别并拦截攻击链”。 |
| 响应算力（本回合打牌费用） | 清楚 | HUD 与卡牌消耗一致；比旧版“费用/行动点”更贴主题。 |
| 临时算力（战斗内额外爆发资源） | 大概懂 | 能理解是战斗内爆发资源，但与响应算力都叫“算力”，需要多玩几回合才完全内化。 |
| 防护 | 清楚 | 敌方攻击压迫下很直观。 |
| 噪声 | 大概懂 | 知道是坏牌/告警债，但需要抽到后才有痛感。 |
| 降权 | 大概懂 | 大概知道是削弱攻击链/敌方执行窗口；数值收益不如伤害和防护直观。 |
| 法门 / 长期能力 | 清楚 | 工具/遗物奖励语义清楚，像 Slay the Spire 的 relic。 |
| 攻击链反制 | 大概懂 | 日志很有安全味，但“何时被动触发/主动打断/窗口 readiness”仍偏专家。 |

11. “响应算力”和“临时算力”是否容易混淆？  
    - **有点混**  
    建议怎么改：保留现命名，但 HUD 上给临时算力加副标题“战斗内储备 / 不随回合刷新”，第一次获得临时算力时弹一条短 cue。

## 4. 战斗信息层级

12. 战斗界面现在是否容易先看到最重要的信息？  
    评分 1-5：**4**  
    你第一眼看到的是：**敌方意图 / 建议响应 / 手牌**。攻击链详情已经不再抢第一眼，这是 v0.2.8 以来最大的体验改进。

13. 专家攻击链详情折叠是否有帮助？

## 5. 地图、事件、维护、商店

14. 地图上选路线时，你是否知道当前应该关注哪些节点？  
    评分 1-5：**5**  
    “待侦察”远端节点是否降低了信息压力：**是**。当前可选节点 + 下一跳说明很有效，我能做“先战斗补构筑 / 先事件换弹性”的选择。

15. 事件选择的“预计结果”是否足够清楚？  
    评分 1-5：**4**  
    哪个事件最清楚 / 最不清楚：最清楚是“短暂维护窗口：升级剧本 vs 申请预算+噪声”；收益/代价明确。最不清楚的是按钮形态，底部“点击提交值班结论”更像提示文案，不够像按钮。

16. 升级界面的前后变化是否让升级更有价值感？  
    评分 1-5：**4**  
    说明：自动 hard probe 中选择“升级剧本”，后续能明显感到 `+` 卡在 C2/凭据战中贡献高。建议升级界面继续强调“升级后多了什么关键词/数值”。

17. 商店里的“推荐理由/构筑方向”是否让你更想购买某些牌或工具？  
    评分 1-5：**4**  
    你买/没买某个东西的原因：normal probe 在商店只买 `溯源加权`，story probe 买 `弹性算力 + YARA 命中 + 沙箱引爆`。推荐理由能支持“围绕 IOC/溯源/爆发”做构筑，但商店仍可更明确标出当前牌组短板，如“你现在缺防护/缺终结/缺清噪”。

## 6. 奖励页与 Boss

18. 奖励页第一眼是否在看三张候选牌？  
    - **是，候选牌最明显**  
    说明：奖励页聚焦已经奏效；预算回收、候选剧本、工具入库是次级摘要，三张牌是主视觉。

19. 候选牌下方的预计效果、取证价值、战术代价是否帮助你选择？  
    评分 1-5：**4**  
    说明：有帮助，尤其能避免只按伤害选牌。但短视口下卡牌下半部分视觉被截断，影响“读完再选”。

20. 高危战 / Elite 获得工具时，工具是否像一个真正奖励？  
    评分 1-5：**4**  
    你记住了哪个工具？为什么：`弹性算力` 和 `溯源加权`。前者改变出牌上限，后者明显服务 IOC/溯源构筑。相比 v0.2.7，工具更像构筑方向而不是随机 buff。

21. Boss 战是否比普通战更有阶段变化、压迫感和记忆点？  
    评分 1-5：**4**  
    你是否看懂 Boss 阶段文案和勒索倒计时？**大体看懂。**  
    说明：`勒索核心` 在自动 probe 中三档均通关，但 normal/hard 终局血量分别为 41/84、32/74，说明 Boss 有压迫但未过度。阶段文案方向正确；如果要更有记忆点，可以在进入擦除窗口时给更强的视觉/音效/日志爆点。

## 9. 最重要的开放反馈

25. 如果只能优先改一件事，你希望改什么？为什么？

**优先做“短视口下奖励/事件/商店卡片的底部 CTA 与关键信息完整可见”。** 现在核心玩法已经能跑通，最大风险不是系统坏，而是试玩者在关键选择页读不完整或不知道哪里提交，导致反馈被 UI 摩擦污染。

26. 哪一刻最有意思、最有“安全攻防”的感觉？

C2 / 凭据 / 勒索战中，`标记 IOC+`、`关联分析+`、`快速 triage` 连续触发“IOC 复核让攻击链暂停扩散”的日志时，最像真正 SOC 在抢窗口；这比普通“打伤害”更有题材差异化。

27. 哪一刻最困惑、最想关掉游戏？

不是卡关，而是第一战初见时信息仍偏密：敌方意图、建议响应、专家详情、资源、日志、手牌全部在场。v0.2.8 已明显改善，但第一战仍建议更强地“只教一个动作”：先照建议打出 1 张关键牌。

28. 你愿不愿意玩下一版？  
    - **愿意**  
    原因：现在已从“题材很有趣的内部原型”进化到“可以稳定给资深卡牌玩家试玩的 demo”。下一版如果补 UI 摩擦、胜利复盘和更多构筑分支，我愿意继续测。

29. 其它建议、吐槽或想看的内容：

- 加一个“本局安全报告”式胜利复盘：MVP 响应动作、阻断的攻击链、最大险情、最终建议。
- 商店/奖励页增加“当前构筑诊断”：缺防护、缺 IOC、缺爆发、牌组太厚、噪声过多。
- Boss 擦除窗口需要更强的仪式感：红色倒计时、日志升级、音效/视频强化。
- 把“降权”的数值收益再翻译成人话：例如“让敌方下次攻击少 X / 让攻击链推进慢一拍”。

## 10. 可选：一句话评价

> 这是一个已经能稳定跑通、题材辨识度很强的 SOC 卡牌 demo；v0.2.8/v0.2.9 最大进步是让玩家知道先看什么，下一步应该优先消除关键选择页的短视口阅读摩擦。
