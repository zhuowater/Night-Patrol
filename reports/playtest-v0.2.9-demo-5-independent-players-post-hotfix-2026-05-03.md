## 0. 强结论

**不建议继续加内容。现在最该做的是：Boss/死亡复盘、事件路线补偿、短视口信息层级。**

这轮 5 个模拟玩家只有 **1/5 通关**：小屏轻度玩家保守路线险胜，其余 4 人都死在 Boss。这个结果比上一轮更尖锐，原因不是 hotfix 破坏了数值，而是这组 seed/策略更贴近“真实玩家不一定最优”：

1. 新手会过度防守，拖到 Boss 长战耗死。
2. 肉鸽玩家会贪 Elite，能爽但会把血线压进死亡区。
3. 安全从业者会多走事件读文本，但事件路线构筑补偿不足。
4. 小屏玩家能玩完，但 UI 负担仍重。
5. hard 玩家能被杀，这是对的；但死亡需要可学习。

## 4. 聚合问题分级

### P0 / 闭门试玩前优先修

1. **Boss/死亡复盘缺失会污染所有反馈**  
   - 证据：4/5 死于 Boss，但每类玩家死亡原因不同：新手拖长战、肉鸽贪 Elite、安全玩家事件路线缺构筑、hard 玩家血线赌博。
   - 建议：胜利/死亡页升级为“本局 SOC 复盘”：路线、Boss 入场血量、关键工具、最大伤害、最大承伤、死亡前 3 个拐点、推荐下一局策略。

2. **事件路线构筑补偿不足**  
   - 证据：P3 多事件路线进 Boss 工具为 0，死亡；安全玩家反而最容易走事件，因为题材吸引。
   - 建议：事件至少部分给“构筑方向明确”的收益，例如指定 IOC/降噪/防护三选一，而不是只给叙事取舍。

3. **短视口仍需要信息层级，不只是重叠修补**  
   - 证据：P4 通关但反馈是“监控屏塞太多窗口”；浏览器第一战显示蓝字重叠已缓解，但建议框、态势栏、手牌同时抢注意力。
   - 建议：短视口下默认折叠专家态势；值班建议改为一行 + 可展开。

### P1 / 下一版高收益

1. **地图节点选择要更明确“点哪里”**：左侧地图节点和右侧详情卡都可点，功能重复但缺显式 CTA。
2. **奖励/商店推荐要从“单卡说明”升级为“构筑诊断”**：告诉玩家当前缺防、缺爆发、缺降噪还是缺抽牌。
3. **Boss 阶段提示要更戏剧化**：阶段转折、擦除窗口、勒索倒计时需要声音/视觉警报和明确后果。

### P2 / 可后置 polish

- Release 下载指引继续保留在顶部，减少普通玩家选错包。
- “响应算力 / 临时算力 / 降权 / IOC”继续做 tooltip 或首见解释。
- 通关页加入本局称号/评分，提高分享欲。

## 5. 分类：设计 / 平衡 / Bug / Polish

### Design changes needed

- 胜利/死亡复盘是当前最高优先级，不是装饰；它决定玩家能否形成下一局目标。
- 事件路线需要明确构筑回报，否则安全题材玩家会被“读故事”诱导进弱路线。
- 短视口下应默认“只显示能操作的信息”，专家态势降级为可展开。

### Balance adjustments

- 暂不建议削弱 hard；P5 死亡合理。
- normal 的 Boss 对非最优路线偏硬，先补复盘和路线提示，再决定是否调数值。
- story 档新手拖 26 回合死亡，说明 story 可能需要 Boss 前额外提示/保底，而不是整体加血。

### Bug reports

- 本轮未发现阻塞性实现 bug。
- 手牌蓝色预计文字 hotfix 后，浏览器截图未见明显与白色描述重叠。

### Polish items

- 地图右侧详情卡增加“进入该节点”按钮文本。
- 结束回合按钮更突出。
- Boss 低血阶段音画警报。
- 小屏布局下建议框收纳。

## 6. 给真实 5-10 人闭门试玩的问题

1. 你第一局死/赢后，能不能复述“为什么”？如果不能，缺什么信息？
2. 你在地图上是点左侧节点还是右侧卡片？有没有犹豫？
3. 事件节点让你觉得赚了、亏了，还是只是读了一段故事？
4. Boss 入场前你知道自己血线危险吗？
5. 奖励/商店有没有告诉你“当前构筑缺什么”？
6. 小屏玩家：哪些信息你完全不看？哪些遮挡操作？

## 7. 下一步建议
