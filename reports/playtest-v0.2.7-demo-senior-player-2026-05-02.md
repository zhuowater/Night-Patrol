## 0. 一句话结论

**v0.2.7-demo 已经从“能跑的原型”进入“有明确差异化卖点的闭门试玩版”：安全题材不是贴皮，攻击链态势、C2 信标、IOC、噪声、勒索核心这些机制已经能形成可读的战斗语言。**

但它现在最大的问题不是内容不够，而是：**第一局信息密度过高、UI 层级抢注意力、引导不足导致新玩家会在“看起来很专业”和“我到底该点哪张牌”之间摆动。**

资深玩家愿意继续玩，因为能看到构筑胚芽；普通玩家可能第一战就被术语墙挡住。

## 3. 前 5 分钟体验

### 玩家是否理解目标？

**部分理解。**

标题页文案非常清楚：凌晨 02:17、接管 SOC、用 IOC / 隔离 / 降噪 / 自动化剧本阻断攻击链。主题立住了。

但进入第一战后，目标从“阻断攻击链”快速展开为：

- 血量
- 防护
- 算力
- IOC
- 噪声告警
- 活动意图
- 攻击链态势
- 推荐反制
- 当前可用牌
- 牌库/弃牌

这些信息都对，但第一局同时出现会压迫玩家。

### 玩家是否理解操作？

**基本理解。**

“点击卡牌或拖出手牌区施放”是有效提示。卡牌可点击，手牌区能读到消耗、类型、效果、预计结果。对资深卡牌玩家很快能上手。

### 情绪反应

- 资深牌游玩家：**感兴趣**，因为机制不是 Slay the Spire 换皮，有安全语义。
- 安全从业者：**会心一笑**，C2、IOC、噪声、凭据窃取、勒索核心这些词有真实感。
- 普通玩家：**可能紧张/困惑**，因为“专业信息很多，但第一张该点什么”不够突出。

## 4. 核心玩法评测

### 4.1 战斗系统

#### 做得好的地方

1. **攻击链态势是最大卖点**
   - C2 操作员不只是“敌人攻击 12”，它有 C2 信标、噪声注入、IOC 拦截窗口。
   - 这让安全题材进入机制层，而不是美术/文本贴皮。

2. **卡牌 tooltip 的预计效果很有价值**
   - 如“预计：造成 6 伤害”“预计：叠 2 IOC 与 2 暴露面”。
   - 这降低了新机制学习成本。

3. **推荐反制方向开始有设计师手感**
   - 战斗中出现“优先标记 IOC 与 YARA 命中；若它开始增强，保留算力给全域清剿”。
   - 这是安全桌游/牌游里很少见的“态势-行动”翻译。

4. **防护、抽牌、IOC、噪声之间已有循环**
   - 标记 IOC → 关联分析多抽 / 溯源打击爆发。
   - 噪声告警污染牌组、留手扣血，能制造“必须处理告警债”的安全感。

#### 当前痛点

1. **第一战决策焦点不够强**
   - 战斗屏同时给了完整态势面板、术语解释、推荐反制、手牌、敌人意图。
   - 资深玩家能读，但新玩家需要一个更强的“这一回合推荐先打：加固规则/阻断连接/标记 IOC”。

2. **能量与算力存在命名/视觉混淆**
   - 卡牌消耗显示“算力”，玩家面板也有“算力”，底部 orb 显示 `0/3` 或 `3/3`。
   - 如果“energy”和“incense/算力”不是同一资源，需要改名或强视觉区分。
   - 如果是同一资源，则 HUD/面板应统一表达。

3. **C2 信标的反制很棒，但需要首次弹窗/微引导**
   - 当前显示“还差 1 IOC”“IOC ≥ 1”，资深玩家能理解。
   - 新玩家可能不知道“我该用哪张牌给 IOC”。
   - 建议首次出现 C2 时高亮手中可施加 IOC 的牌；如果没有，提示“下回合寻找 IOC 牌或先补防护”。

### 4.2 构筑系统

#### 做得好的地方

- 奖励不是纯随机堆牌，会显示“适合构筑”“为什么值钱”。
- 工具/遗物解释非常有用，例如“封禁热键：每场战斗第一张攻击牌额外造成 4 点伤害；适合攻击牌压血”。
- 升级窗口有明确意义，资深玩家会优先升级核心 IOC 或抽牌牌。

#### 当前不足

- 当前跑局中胜利普遍可达，但构筑路线还偏“泛用好牌优先”。
- 牌与遗物之间已有协同，但缺少足够鲜明的 archetype 终局感。比如：
  - IOC 爆发流
  - 噪声治理/降噪流
  - 防护反打流
  - 自动化低费循环流
- 这些流派已有雏形，但奖励界面可以更明确标记：“这张牌强化 IOC 爆发流”。

### 4.3 路线/地图

#### 做得好的地方

- 地图节点说明非常明确：风险、收益、节奏、下一跳。
- 维护/商店/事件/精英的战略含义已经建立。
- “当前可选节点”列表比只看地图点更适合小屏/非资深玩家。

#### 当前问题

- 地图节点很多，禁用节点也都读屏/DOM 可见，视觉上会显得复杂。
- 对资深玩家 OK；对普通玩家建议第一局只强调当前可选 2-3 个节点，远端节点弱化。

## 5. UI/UX 评测

### 标题页

优点：
- 氛围强，有“夜班 SOC”味道。
- 三档难度文案清楚，推荐默认 normal 合理。
- “接管夜班”CTA 很贴题。

建议：
- 首次试玩建议默认选择 story 或保留 normal 但提示“推荐第一次也可以选演示模式”。
- 标题页加“预计 15-25 分钟”能降低玩家心理成本。

### 地图页

优点：
- 当前可选节点说明是亮点。
- 风险/收益/节奏/适合条件让路线选择更有策略感。

问题：
- 全图信息密度较高，禁用节点过多会造成“我是不是该看完所有节点”的压力。

### 战斗页

优点：
- 敌方意图、攻击链态势、反制窗口已经具备产品辨识度。
- 手牌效果可读，预计效果能减少误操作。
- 主题词和机制绑定较紧。

问题：
- 第一回合缺少主引导。
- 右侧/中部态势面板很有价值，但占据大量认知预算。
- 资深玩家能吸收，普通玩家需要折叠/渐进显示。

### 奖励页

实际截图分析显示：

优点：
- “处置奖励 · 复盘选择”清楚。
- +预算、候选剧本、工具入库的信息块清晰。
- “适合构筑 / 为什么值钱”非常应该保留，这是本作区别普通卡牌 demo 的关键体验。

问题：
- 页面同时有奖励总结、工具解释、三张候选牌、日志，信息层级略拥挤。
- 真实截图里候选卡牌虽然 DOM 可见，但视觉上容易被工具解释和响应日志抢注意力。
- 建议把“请选择一张响应动作”做成更明确的主标题，并让三张候选牌成为第一视觉焦点。

### 维护窗口/商店/事件

本次 UI 覆盖中已经进入维护窗口并截图；完整视觉分析因工具超时未完成，但从引擎跑局和界面结构看：

- 维护窗口的回血/升级是必要且有效的压力释放点。
- 商店在 normal/hard 中有实际价值，尤其是买关键牌/工具。
- 事件给了“安全运营取舍”的空间，是题材表达的重要阵地。

建议下一轮重点人工检查：
- 维护窗口是否清楚展示“回血 vs 升级”的长期收益差异。
- 商店是否给“删除噪声/低效牌”的足够强提示。
- 事件是否避免只有正收益，最好有风险代价和长期后果。

## 6. 主题/叙事评测

### 最强点

**安全主题已经机制化。**

这点很重要。很多垂直题材游戏只把怪物改名为“漏洞”“木马”，但《夜巡 SOC》现在已经把：

- IOC
- C2 信标
- 噪声告警
- 凭据窃取
- 勒索核心
- 自动化剧本
- 威胁情报市场
- 维护窗口

转成了玩家能操作的资源、状态、路线、反制窗口。

### 叙事气质

当前气质是：

> 不是英雄打怪，而是值班工程师在凌晨用有限算力和预算维持边界。

这个方向非常对。它比“赛博修仙/黑客大战”更稀缺，也更容易形成独特口碑。

### 风险

- 术语太多时，非安全玩家会被排斥。
- 安全玩家会要求准确性；如果某些词只是好听但机制不对，会被挑刺。

建议：
- 保留术语，但加“玩家语言翻译”：
  - IOC = 给敌人贴可被后续牌放大的标记
  - C2 信标 = 倒计时后塞噪声/增强敌人
  - 噪声告警 = 污染牌组的坏牌

## 7. 视听/美术/氛围

优点：
- 暗色、金色、SOC/玄学混合视觉已经形成辨识度。
- 视频背景和过场提升“不是普通网页 demo”的质感。

- 信息密集屏幕需要更强的字号层级和留白。

## 8. 平衡评价

### 当前难度曲线

- 第一战：正常，有教学价值。
- 第一个精英：开始产生压力。
- 中段 C2/凭据窃取：是当前体验核心。
- Boss：能收束，但“勒索倒计时/核心擦除”的戏剧张力还可以更强。

### 资深玩家感受

- normal 胜利剩 41/84：舒服，说明路线和构筑有意义。
- hard 胜利剩 32/74：有压力但未崩，说明 hard 可作为资深档。
- story 剩 86/96：更像展示档，不应用作平衡判断。

### 可能的问题

- 如果玩家拿到强抽牌/IOC/防护，通关稳定性较高。
- 噪声作为负面状态很有意思，但当前还没有强到迫使玩家专门构筑“降噪”。
- Boss 战目前在确定性策略中 5-6 回合结束，终局压迫感可以再做一点机制峰值。

## 9. Bugs / 技术风险

### 发现的问题/风险

1. **浏览器 preview 端口残留**
   - 测试中发现多个 Vite preview 进程曾占用 4173，导致后续 preview 启动报端口占用。
   - 这不是游戏 bug，但说明本地测试脚本/开发流程需要清理 preview 进程。

2. **视觉分析工具对复杂战斗屏多次超时**
   - 截图成功，但自动视觉分析超时。
   - 间接说明战斗屏视觉复杂度较高；当然这也可能是工具问题，不能完全归咎 UI。

3. **DOM/无障碍文本过密**
   - 地图禁用节点和大量按钮文本全部暴露，读屏/自动测试视角很重。
   - 如果未来做可访问性，需要更精细的 aria-label 分层。

4. **发行包运行验证还应补 Electron 真机启动截图**
   - 本次主要通过下载/解包 + browser preview + build/check 验证。
   - 下一轮正式发布前建议在三平台至少做一次真机打开截图。

## 10. P0/P1/P2 优先级

### P0 — v0.2.8 必做

1. **First-run 引导**
   - 第一战第 1 回合高亮推荐牌。
   - 首次出现 C2 信标时，明确提示“用 IOC 牌可拦截”。
   - 首次出现噪声时，提示“这是坏牌，留在手里会扣血/污染循环”。

2. **战斗信息层级重排**
   - 主焦点顺序建议：敌方意图 → 推荐行动 → 手牌 → 攻击链详情。
   - 攻击链详情可默认简版，点击展开专业细节。

3. **算力/能量命名治理**
   - 明确卡牌费用、回合能量、临时算力是否同一概念。
   - 如果不是同一概念，必须改名或强区分。

4. **奖励页主选择前置**
   - 三张候选牌成为视觉第一焦点。
   - 工具解释和响应日志降级为侧栏/折叠信息。

### P1 — 强烈建议

1. **路线图弱化不可选节点**
   - 第一局只强调当前可选节点与下一层预览。

2. **构筑流派标签化**
   - 奖励卡直接标：IOC 爆发 / 防护反打 / 自动化循环 / 降噪治理。

3. **Boss 机制峰值加强**
   - 勒索核心应有更强终局表达：倒计时、阶段转换、必须处理的勒索锁定牌等。

4. **闭门试玩反馈表内置链接或 Release 明示**
   - 降低反馈收集成本。

### P2 — 后续 polish

1. 顶部署名/版权信息在战斗中弱化。
2. 响应日志支持折叠。
3. 奖励/商店/维护页面增加“推荐选择”但允许玩家反着来。
4. 增加通关总结：核心构筑、关键工具、最大风险、玩家风格评价。

## 11. 分类清单

### Design changes needed

- 第一战缺少渐进式教学。
- 攻击链态势信息很好但默认过满。
- 奖励页的“选择动作”不够视觉优先。
- Boss 的终局压迫还不够像最终考试。

### Balance adjustments
