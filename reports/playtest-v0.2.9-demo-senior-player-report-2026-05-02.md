# 《夜巡 SOC：边界告警》v0.2.9 模拟资深玩家试玩报告

- 日期：2026-05-02
- 玩家画像：资深卡牌/肉鸽玩家，理解基础安全术语，重点评估新版本是否已具备闭门试玩条件。
- 参考：`playtest-v0.2.7-demo-senior-player-2026-05-02`、`v0.2.8-feedback-form.md`、v0.2.9 反馈闭环计划、当前最新完成状态。
- 结论：**可以进入 5-10 人闭门试玩；不建议先扩内容，建议先修两个 UI 摩擦点并建立反馈汇总。**

## 1. 执行摘要

当前版本相对 v0.2.7 的核心改善成立：

1. **第一局可读性明显提高。** 首次 cue、回合级建议、资源命名、奖励聚焦、地图渐进披露都在发挥作用。
2. **完整跑局稳定性达标。** 自动 probe 在 story / normal / hard 三档都能通关；`npm run check` 与 `npm run build` 通过。
3. **题材差异化更清楚。** 最有价值的体验不是“打伤害”，而是 IOC、C2、凭据、勒索、攻击链反制日志连起来后形成的 SOC 抢窗口感。
4. **当前主要问题不是系统深度，而是关键选择页的 UI 摩擦。** 短视口下奖励候选牌、事件选择 CTA 容易读不完整或不像按钮。

建议优先级：

| 优先级 | 建议 | 理由 |
|---|---|---|
| P0 | 修短视口奖励页/事件页/商店页底部 CTA 与关键信息可见性 | 直接影响闭门试玩反馈质量，容易让玩家把 UI 摩擦误判成规则难懂 |
| P1 | 胜利复盘增加“本局安全报告” | 帮玩家解释自己的构筑，提升分享/复盘价值 |
| P1 | 商店/奖励加入当前构筑诊断 | 让资深玩家更愿意进行构筑决策，而不是凭直觉选牌 |
| P2 | Boss 擦除窗口强化视听/倒计时仪式感 | 提升记忆点，但不阻塞试玩 |
| P2 | 降权/临时算力进一步人话化 | 概念已能理解，但仍有学习成本 |

## 4. 玩法与数值体感

### 4.1 难度曲线

- story：非常稳，适合作为首次闭门试玩默认推荐。终局 86/96，容错很高。
- normal：有压力但可控，终局 41/84，适合卡牌玩家。
- hard：仍可胜利但血线明显吃紧，终局 32/74，能暴露构筑选择质量。

当前不建议立刻大改数值。更应该先收真实玩家样本，看：

- 新手是否在第一战理解出牌；
- 普通玩家是否在 Elite 前后血线崩掉；
- Boss 是否被理解为“最后考试”而不是普通高血量敌人。

### 4.2 构筑空间

本轮最强体感是 IOC/溯源/爆发构筑：`标记 IOC+`、`关联分析+`、`快速 triage`、`沙箱引爆`、`YARA 命中`、`溯源打击+`。它们能和攻击链反制日志形成主题闭环。

较弱体感是：

- `降权` 的收益不够立即；
- 噪声污染如果没有抽到，代价不够痛；
- 商店还不能主动指出当前牌组短板。

## 5. UI/UX 发现

### 5.1 已达标

- 标题页：清楚，能启动游戏目标想象。
- 地图：当前可选节点和下一跳说明有效。
- 战斗：默认不让专家攻击链抢主视觉是正确方向。
- 奖励：三张候选牌终于是第一眼主角。

### 5.2 需要优先修

#### P0-A：短视口下奖励页候选牌内容容易被截断

- 影响：玩家可能在没读完预计效果/取证价值/战术代价时就选牌。
- 建议：奖励页在短视口下改为更紧凑卡片、允许内部滚动、或把 CTA 固定并保证效果摘要完整可见。

#### P0-B：事件选择 CTA 不够像按钮

- 影响：玩家能读懂收益/代价，但不一定一眼知道哪里提交。
- 建议：将“点击提交值班结论”改成明确按钮样式，如高亮边框/填充/hover，文案可改为“选择：升级剧本”。

## 6. 闭门试玩建议

### 6.1 推荐分发策略

- 默认建议试玩者选择 **普通值班 / normal**；完全无卡牌经验者选 story。
- 目标样本：5-10 人，其中至少：
  - 2 名卡牌/肉鸽玩家；
  - 2 名安全/技术背景玩家；
  - 2 名普通玩家或轻度策略玩家。

### 6.2 反馈收集时重点追问

1. 第一战是否知道先做什么？
2. C2/IOC 是否一眼理解？
3. 奖励页是否能读完三张牌再选？
4. 哪个安全术语最有味道，哪个最不懂？
5. Boss 是否像一次最终考试？
6. 通关后能否讲出自己的构筑？

### 6.3 决策门槛

- 若 ≥40% 玩家提到“按钮/卡片看不完整/不知道点哪里”：先修 UI，不扩内容。
- 若 ≥40% 玩家第一战仍不知道先做什么：继续强化第一战引导和建议响应。
- 若多数玩家通关但说“复盘没记忆点”：做胜利安全报告。
- 若多数玩家说“内容少但想玩下一版”：再进入 v0.2.10 内容扩展。

## 7. 结论

当前版本已经具备闭门试玩条件。它最重要的进步是：**从“安全主题卡牌系统已经存在”变成“玩家大体知道自己在 SOC 值班中做什么”。**

不要急着加新敌人/新卡/新视频。下一步应先把 5-10 份真实反馈收回来，并在收集前修两个小但关键的 UI 摩擦点：奖励页短视口阅读完整性、事件/选择页 CTA 按钮感。这样收回来的反馈才会真正指向玩法与内容，而不是被界面摩擦污染。
