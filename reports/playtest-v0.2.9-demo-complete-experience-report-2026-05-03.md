## 1. 一句话结论

**这版已经能让玩家理解“我是 SOC 夜班值守者”的身份，也能跑出完整肉鸽闭环；但还不应该继续堆新内容。下一步最该做的是：本局复盘页、事件路线补偿、短视口信息层级。**

这轮 5 个模拟玩家只有 **1/5 通关**，另外 4 人都死在 Boss。这个结果本身不等于“数值坏了”，更像是当前体验的真实问题被放大了：玩家会死，但死后不知道自己是因为路线、构筑、血线、Boss 机制，还是单纯被数值压死。

换句话说：**当前最大风险不是失败率，而是失败不可学习。**

## 3. 五人试玩结果总览

| 玩家 | 画像 | 环境/视口 | 难度 | 结果 | 终局血量 | 核心路线 | 战斗回合 |
|---|---|---|---|---|---:|---|---|
| P1 | 普通新手 | Windows / Chrome / 1366×768 | story | 失败 | 0/96 | 普通战 + 事件 + 多维护 → Boss | 6, 9, 7, 26 |
| P2 | 卡牌肉鸽 | Windows / Chrome / 1920×1080 | normal | 失败 | 0/84 | 事件 + 多 Elite → Boss | 4, 11, 4, 8, 7, 13 |
| P3 | 安全从业者 | macOS / Safari / 1440×900 | normal | 失败 | 0/84 | 大量事件 → Boss | 4, 5, 11 |
| P4 | 轻度小屏 | Linux / Firefox / 1280×581 | normal | 胜利 | 13/84 | 事件 + 维护 + 商店 → Boss | 4, 4, 10 |
| P5 | 硬核挑战 | Windows / Chrome / 2560×1440 | hard | 失败 | 0/74 | 多普通战 + 多 Elite + 商店 → Boss | 3, 3, 5, 5, 5, 5, 2 |

### 关键读法

- **唯一通关者 P4 不是最硬核玩家，而是低风险路线玩家**：说明游戏不是完全不可通，但容错窄。
- **P1 在 story 难度仍 Boss 长战死亡**：新手不是只需要更低敌人数值，还需要被教会“什么时候收口、什么时候爆发”。
- **P2/P5 贪 Elite 死亡是合理的**：肉鸽风险回报成立，但死亡页必须告诉玩家自己从哪里开始赌命。
- **P3 安全玩家死亡最值得重视**：越喜欢题材、越愿意读事件的人，反而可能因为事件路线构筑收益不足而进入弱路线。

## 4. 首 5 分钟体验

### 4.1 能否理解目标？

**基本能。** 标题、文案、卡牌命名、敌人类型都能让玩家快速理解：这不是传统修仙/地牢皮，而是“夜间 SOC 值守 + 安全事件响应”的卡牌肉鸽。

尤其是这些元素有效：

- “边界告警 / 高危入侵 / 核心域控”等节点命名；
- “端口扫描器 / 钓鱼载荷 / 凭据窃取器 / C2 操作员 / 勒索核心”等敌人；
- “标记 IOC / 沙箱引爆 / YARA 命中 / 还原时间线 / 自动化响应”等卡牌；
- 值班建议、情报市场、维护窗口等系统包装。

### 4.2 能否理解操作？

**能开始玩，但还不够顺。** 标题页 CTA 清楚，战斗中卡牌/结束回合基本可推断。但地图页有一个明显问题：左侧节点和右侧详情卡都像可操作入口，缺一个强 CTA 指向“进入该节点”。

对首次玩家来说，这种犹豫会破坏节奏：不是不知道游戏目标，而是不确定界面意图。

### 4.3 情绪反应

- 前中期：新鲜、有题材差异，安全玩家和肉鸽玩家都会被术语和构筑钩住。
- Boss 前：压力增加合理，但危险预警不足。
- 死亡后：反馈断裂。玩家知道“输了”，但不知道“为什么输”。

## 5. 核心循环体验评估

### 5.1 已经成立的部分

#### A. 题材不是贴皮

游戏最强的资产是：安全语义和卡牌机制有一定对应关系。比如 IOC、YARA、沙箱、溯源、降噪、自动化响应这些词不是纯装饰，能让安全从业者产生“这东西懂一点行话”的信任。

#### B. 一局结构完整

标题 → 地图 → 战斗 → 奖励 → 事件/商店/维护 → Boss → 胜负结算，这个第一章 vertical slice 是完整的。它已经具备闭门试玩价值。

#### C. 不同路线确实带来不同体验

- Elite 路线：爽、强、危险。
- 事件路线：文本感强，但收益不足。
- 商店/维护路线：更稳，更适合轻度玩家。
- hard 路线：能快速杀死贪心玩家，挑战感存在。

### 5.2 现在最伤体验的部分

#### A. Boss 是所有体验问题的汇合点

4/5 玩家死在 Boss，但死因并不相同：

- P1：过度防守，拖到 26 回合耗死。
- P2：Elite 贪收益后血线不足。
- P3：事件路线缺工具，构筑贫弱。
- P5：hard 三 Elite 入 Boss 前只剩 9 血，属于高风险赌博。

如果游戏只显示“失败”，玩家会把这些不同问题都归因为“Boss 太强”。这会污染真实玩家反馈，也会误导后续调参。

#### B. 事件路线奖励密度不足

安全从业者最可能主动走事件，因为他们会想看文本、看安全语境。但 P3 大量事件后工具为 0，最终死于 Boss。这个问题危险在于：**最吃题材的玩家可能被题材诱导到最弱路线。**

#### C. 小屏体验从“文字重叠”变成“信息过载”

hotfix 解决了局部文本可读性，但短视口下仍有太多并列信息：态势、建议、敌方意图、手牌、按钮、日志/说明同时争夺注意力。下一步不是继续微调字号，而是做信息层级。

## 6. 分玩家体验复盘

### P1 普通新手玩家：保守但不可学习的失败

- **结果**：story 难度失败，Boss 战 26 回合死亡。
- **喜欢点**：前半段压力温和，安全卡牌名有新鲜感。
- **痛点**：不知道什么时候应该从防守转为输出；死亡后不知道错在哪里。

**判断**：story 难度不应该保证玩家闭眼通关，但应该保证失败后能学到一件事。P1 的问题不是“Boss 数值一定过高”，而是游戏没有告诉新手：拖长战也是一种失败路径。

建议：story 难度 Boss 前给一次明确提示，例如：

> “勒索核心会越拖越危险。若你缺少爆发牌，请优先压低威胁停留时间，而不是继续堆防护。”

### P2 卡牌肉鸽玩家：能爽，但缺少构筑诊断

- **结果**：normal 失败，Boss 前 35/84，13 回合死亡。
- **喜欢点**：Elite 工具、YARA/溯源/沙箱链条有构筑感。
- **痛点**：地图远期收益和 Boss 入场风险不够可视化。

**判断**：P2 的死亡是健康的，但需要复盘页把失败解释为：“你选择了高危路线，获得了 X 个工具，但以 Y 血进入 Boss，且缺少 Z 类型能力。”这样肉鸽玩家才会想再来一局优化路线，而不是觉得被数值闷死。

### P3 安全从业者：题材吸引，但路线惩罚过重

- **结果**：normal 失败，多事件路线，工具为 0。
- **喜欢点**：术语、事件、攻防语义不是空皮。
- **痛点**：事件路线像在读世界观，但没有给足构筑补偿。

**判断**：这是本轮最重要的产品风险。安全从业者是本作天然种子用户之一。如果他们因为“想看安全事件”而被系统性导向弱路线，真实闭门试玩会出现一种很糟的反馈：他们喜欢题材，但觉得游戏不尊重自己的选择。

建议：事件不必全变强，但至少要给方向明确的收益：

- 给一张与事件主题绑定的牌；
- 给一次“从 IOC / 降噪 / 防护 / 爆发中选一类补强”；
- 给短期 debuff + 长期工具，而不是纯资源取舍。

### P4 轻度策略/小屏玩家：能通关，但 UI 负担高

- **结果**：normal 胜利，终局 13/84。
- **喜欢点**：低风险路线也能打完，不被迫走 Elite。
- **痛点**：1280×581 下仍像监控屏塞满窗口。

**判断**：这是证明游戏“可通”的关键样本。但这个通关很险，且 UI 压力大。小屏玩家不一定抱怨数值，他们更容易因为信息太多而做低质量决策。

建议：短视口默认折叠专家态势；值班建议变成一行摘要 + 展开；结束回合按钮更突出。

### P5 硬核挑战玩家：死亡合理，但需要战报

- **结果**：hard 失败，Boss 前 9/74，两回合死亡。
- **喜欢点**：高危入侵给工具，风险回报明确。
- **痛点**：Boss 入场血线预警不足，死亡没有复盘。

**判断**：hard 杀死三 Elite 贪心玩家是对的，不建议为了 P5 直接削弱 hard。真正缺的是战报：告诉玩家“你在第几层开始赌命、赌到了什么、死于什么”。

## 7. 设计 / 平衡 / Bug / Polish 分类

### 7.1 Design changes needed

1. **胜利/死亡复盘页必须优先做**
   - 显示路线、结果、Boss 入场血量、关键卡/工具、最大伤害、最大承伤、死亡前 2-3 个转折点、下一局建议。
   - 这是试玩前的核心功能，不是锦上添花。

2. **事件路线需要构筑补偿**
   - 当前事件文本吸引安全玩家，但收益不足会把他们带进弱路线。
   - 事件应该给“方向明确”的收益，而不是只有叙事选择。

3. **短视口做信息层级，而非继续局部补丁**
   - 专家态势默认折叠；建议框压缩；关键行动按钮强化。

### 7.2 Balance adjustments

1. **暂不建议直接削 hard**
   - P5 死亡符合 hard 对贪心路线的惩罚。

2. **normal Boss 是否过硬，先等复盘页后再判断**
   - 目前玩家无法区分路线失败、构筑失败和 Boss 数值失败。没有复盘就调数值，容易误调。

3. **story Boss 需要“教学式保底”而不是单纯加血**
   - P1 不是血少死，而是拖长战死亡。
   - story 可以加入 Boss 前提示、推荐构筑、或一次性应急资源。

### 7.3 Bug reports

本轮未发现阻塞性实现 bug。

已观察到的 UI hotfix 效果：手牌蓝色预计文字没有明显继续压白字。后续问题主要是信息密度和层级，而不是单个文字重叠 bug。

### 7.4 Polish items

- 地图详情卡增加明确按钮：“进入该节点”。
- 结束回合按钮强化视觉优先级。
- Boss 阶段转折加入更强音画警报。
- 通关/失败页加入本局称号、评分、分享文案。
- 术语 tooltip 继续补：响应算力、临时算力、降权、IOC、YARA 等。

## 8. 试玩前优先级

### P0：闭门试玩前必须做

1. **本局 SOC 复盘页**
   - 最小可行版本即可：路线、结果、Boss 入场血量、关键牌/工具、死亡/胜利原因推断、下一局建议。
   - 目标：让玩家死后能说出“我下局要改什么”。

2. **事件路线补偿**
   - 至少改 2-3 个高频事件，让它们能给明确构筑方向。
   - 目标：安全玩家走事件不再天然变弱。

3. **短视口信息层级**
   - 默认折叠专家态势，压缩建议框。
   - 目标：让 1280×581 这种低高度视口可舒服完成一局。

### P1：下一版高收益

1. 地图节点加入强 CTA。
2. 奖励/商店加入“当前构筑缺口”提示。
3. Boss 分阶段反馈更戏剧化。

### P2：可后置

1. 通关页称号/评分/分享。
2. 更多术语 tooltip。
3. Release 下载页继续优化平台选择说明。

## 9. 是否适合进入真实闭门试玩？

**判断：可以准备，但不建议立刻拉 5-10 个真实玩家开测。**

原因：现在真实玩家大概率会集中反馈“Boss 太难 / 信息太多 / 不知道怎么选”，但这些反馈会混在一起，难以判断是数值、路线、构筑还是 UI 问题。先做一个轻量复盘页，真实试玩质量会高很多。

更好的顺序是：

1. 先做 **本局 SOC 复盘页**。
2. 顺手补 **事件路线构筑收益**。
3. 修 **短视口层级**。
4. 再拉真实 5-10 人闭门试玩。

这样真实玩家的反馈会从“我不知道为什么死”升级为“我知道我死因，但我觉得某个选择/数值/提示不合理”。后者才是可执行反馈。

## 10. 给真实玩家的试玩问题清单

建议闭门试玩时直接问：

1. 第一局结束后，你能不能复述自己为什么赢/输？
2. 你在 Boss 入场前是否意识到血线危险？
3. 你选奖励时，是因为喜欢名字、看数值，还是觉得它补了当前构筑？
4. 你走事件节点时，觉得自己赚了、亏了，还是只是读了一段故事？
5. 地图页你第一反应点哪里？左侧节点还是右侧卡片？
6. 小屏/笔记本玩家：哪些信息你完全不看？哪些信息挡住操作？
7. 你愿不愿意马上再开一局？如果愿意，是想验证什么新策略？如果不愿意，卡在哪里？

## 11. 最终建议

**不要先扩新敌人、新卡、新章节。**

这版最应该做的不是内容量，而是让玩家的每一局变得“可解释、可学习、可复盘”。

最小下一步切片：

> 做一个轻量“本局 SOC 复盘页”：路线、结果、Boss 入场血量、战斗耗时、关键卡/工具、死亡/胜利原因推断、下一局建议。

它会同时解决四类玩家的问题：

- 新手知道自己不是“随便死了”；
- 肉鸽玩家知道下局怎么优化构筑；
- 安全玩家知道事件路线是否值得；
- hard 玩家知道自己是哪一步赌命失败。

这比新增 20 张卡更值钱。
